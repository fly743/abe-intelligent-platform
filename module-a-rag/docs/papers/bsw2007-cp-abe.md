# BSW 2007 CP-ABE 详细知识笔记

## 文献说明 [BSW 2007, PDF 第1页]

本文根据 Bethencourt、Sahai、Waters《Ciphertext-Policy Attribute-Based Encryption》（2007）归纳。文中“页”均指用户提供 PDF 的页序；本文中的医生例子是为解释而构造，不是论文原例。本文解释主要公式和证明思路，不代替原论文证明或密码学实现审计。

## 1. 背景：为什么对密文指定访问条件 [BSW 2007, PDF 第1页]

传统服务器访问控制依赖服务器正确执行授权。如果数据存放在可能被攻破的服务器，攻击者可能绕过服务器权限读取数据。论文考虑将数据加密，并让加密者描述满足什么属性的用户可以解密。加密者不需要预先知道每个合格接收者的身份。加密保护机密性，但不意味着服务器可用性、密钥管理或所有实际攻击问题都自动解决。（来源：摘要、第 1 节，PDF 第 1 页）


## 2. CP-ABE 中谁决定权限 [BSW 2007, PDF 第1–4页]

本论文的 CP-ABE 中，加密者选择访问策略，策略随密文给出；用户私钥关联一组属性；当该私钥所关联的属性满足密文策略时，用户才能解密。属性可以表达角色或部门等资格，密钥由授权机构签发。CP-ABE 把数据拥有者的策略选择与密码操作结合，而不是仅依赖存储服务器判断访问权限。（来源：第 1、3.1 节，PDF 第 1–4 页）


## 3. CP-ABE 与 KP-ABE 的区别 [BSW 2007, PDF 第2页]

| 模型 | 密文关联 | 用户私钥关联 | 策略决定位置 |
| --- | --- | --- | --- |
| 本文 CP-ABE | 属性访问策略 | 属性集合 | 加密者选择密文策略 |
| 论文比较的 KP-ABE | 属性集合 | 访问策略 | 密钥签发方控制私钥策略 |

例如，对“医生 AND 心内科”策略，CP-ABE 加密者将该条件关联密文，而合格用户私钥需关联这两个属性。比较仅针对论文讨论的模型，不应把它当成所有后续变体的完整分类。（来源：第 1 节，PDF 第 2 页）


## 4. 访问结构及单调性 [BSW 2007, PDF 第3–5页]

访问结构 A 是被授权的属性集合的集合；一个集合 S 若属于 A，则满足策略。单调性是：若 S 已被授权，且 S 是 S' 的子集，则 S' 也被授权。增加属性不会使原本满足的单调策略失效。论文主要使用单调访问结构；其讨论把否定属性作为额外属性的可能性，不等于原构造直接支持任意动态否定条件。（来源：第 3.1、4.1 节，PDF 第 3–5 页）


## 5. 访问树和阈值门 [BSW 2007, PDF 第4–5页]

论文用树 T 表示策略。叶节点 x 标记属性 att(x)；内部节点 x 有 num_x 个子节点和阈值 k_x，1 ≤ k_x ≤ num_x。至少 k_x 个子节点满足时该内部节点满足。k_x=1 是 OR，k_x=num_x 是 AND；k-of-n 表示至少满足 n 项中的 k 项。（来源：第 4.1 节，PDF 第 4–5 页）


## 6. 自拟策略树判断实例 [BSW 2007, PDF 第4–5页]

策略为 `(医生 AND 心内科) OR 急诊主管`。用户甲属性 `{医生, 心内科}` 满足左侧 AND，因此满足根 OR；用户乙 `{医生}` 缺少心内科且没有急诊主管，不满足；用户丙 `{急诊主管}` 满足右侧，故满足根。甲、乙、丙分别表示独立私钥的属性，不应把不同用户的属性当成一个用户的属性集合。（例子为本文自拟；规则来源：第 4.1 节，PDF 第 4–5 页）


## 7. 五个算法接口 [BSW 2007, PDF 第3–4页]

- Setup：输入安全参数，输出公开参数 PK 和主密钥 MK。
- Encrypt(PK, M, A)：输入公开参数、消息 M 和访问结构 A，输出关联 A 的密文 CT。
- KeyGen(MK, S)：输入主密钥和属性集合 S，输出与 S 对应的用户私钥 SK。
- Decrypt(PK, CT, SK)：私钥属性满足密文策略时恢复消息；不满足时不能按正确性要求恢复消息。
- Delegate(SK, S')：对 S' ⊆ S，从原密钥生成子集属性的委托密钥；论文将其列为可选接口。

以上是论文接口层的概括，具体系统还需处理身份核验、密钥存储和错误结果。（来源：第 3.1 节，PDF 第 3–4 页）


## 8. 双线性映射与符号 [BSW 2007, PDF 第4–5页]

论文设 G0、G1 为素数阶 p 的乘法循环群，g 是 G0 的生成元，e：G0 × G0 → G1 是有效可计算且非退化的双线性映射。对 u、v ∈ G0 和 a、b ∈ Zp，有 `e(u^a, v^b) = e(u, v)^(ab)`。这是解释后续抵消过程所需的性质；论文用的是对称配对记法，不能据此假设所有现代配对库接口相同。（来源：第 3.2、4.2 节，PDF 第 4–5 页）

主要符号：α、β 为系统随机指数，β 必须可逆；s 为一次加密选取的随机数；r 为某个用户密钥随机数，r_j 为该密钥中属性 j 的随机数；H 将属性字符串映射到 G0，在证明中建模为随机预言机。指数计算在 Zp 中进行。（来源：第 4.2 节、附录 A，PDF 第 5、12 页）


## 9. Setup 主要公式 [BSW 2007, PDF 第5、12页]

论文选择 α、β，公开 `PK = (G0, g, h=g^β, f=g^(1/β), e(g,g)^α)`，保存 `MK = (β, g^α)`；其中 f 用于委托。式中的 1/β 是 β 在 Zp 中的乘法逆元，并非普通实数除法；β=0 时无逆，论文证明中将此情形视为中止。（来源：第 4.2 节、附录 A，PDF 第 5、12 页）


## 10. 加密：秘密沿访问树分发 [BSW 2007, PDF 第5页]

加密者选取随机 s，根节点 R 的多项式满足 q_R(0)=s。节点 x 的多项式次数为 `k_x - 1`；对子节点 x，令 `q_x(0)=q_parent(x)(index(x))`。这使子节点持有与父节点共享值相关的份额；足够多的满足节点可以通过插值恢复上层所需的指数值。这里描述的是论文的树形秘密共享结构，不是独立的实现步骤规范。（来源：第 4.2 节，PDF 第 5 页）


## 11. 加密：密文组成 [BSW 2007, PDF 第5页]

令 Y 为访问树的叶节点集合，论文给出 `CT=(T, C̃=M·e(g,g)^(αs), C=h^s, {C_y=g^q_y(0), C'_y=H(att(y))^q_y(0)}_{y∈Y})`。其中 C̃ 将消息与一次加密的掩码结合；C 用于后续与用户密钥配对；每个叶节点的两个分量与该节点的属性和份额有关。策略 T 包含在该论文构造的密文中，不能假定该方案隐藏策略。（来源：第 4.2 节，PDF 第 5 页）


## 12. KeyGen：私钥和属性绑定 [BSW 2007, PDF 第5页]

为属性集合 S 生成私钥时，论文选取用户级随机 r 和每个属性的随机 r_j，并给出 `D=g^((α+r)/β)`、`D_j=g^r·H(j)^r_j`、`D'_j=g^r_j`。同一用户密钥的分量共享用户级随机量 r；这是理解抗合谋直觉的重要线索。不同用户的私钥分量不能当作同一用户密钥的普通属性清单拼装。（来源：第 4.2 节，PDF 第 5 页）


## 13. 解密：叶节点匹配与插值 [BSW 2007, PDF 第6页]

对于匹配叶节点 x、属性 i=att(x)，论文使用配对计算 `e(D_i,C_x)/e(D'_i,C'_x) = e(g,g)^(r·q_x(0))`；属性不在该用户私钥集合中时该叶节点不满足。内部节点至少收集到阈值数量的满足子节点时，通过拉格朗日插值组合结果。逐层向上，满足整棵树时得到 `A=e(g,g)^(r·s)`。（来源：第 4.2 节，PDF 第 6 页）


## 14. 解密：怎样恢复消息 [BSW 2007, PDF 第5–6页]

因为 `C=h^s=g^(βs)` 和 `D=g^((α+r)/β)`，双线性性质给出 `e(C,D)=e(g,g)^((α+r)s)`。满足树时 A 为 `e(g,g)^(rs)`，所以 `e(C,D)/A=e(g,g)^(αs)`，最终 `M=C̃/(e(C,D)/A)`。这一等式解释正确属性如何消除掩码；它是正确性直觉，不单独构成安全证明。（来源：第 4.2 节，PDF 第 5–6 页）


## 15. 抗合谋：什么不能合并 [BSW 2007, PDF 第2、6页]

抗合谋针对多个原本都不能独立解密的用户联合密钥的情形。例如策略为 `医生 AND 心内科`，甲只有医生、乙只有心内科时，不能仅凭拼合两人的密钥组件解密。论文解释，用户密钥的随机量使组件与各自密钥绑定，跨用户组合无法直接消去对应随机掩码。该描述是论文构造的安全直觉，证明仍须依赖论文模型。（来源：第 1、4.3 节，PDF 第 2、6 页）


## 16. 安全游戏及证明思路 [BSW 2007, PDF 第4、12–14页]

论文的安全游戏允许对手查询多个私钥，限制是每个查询的属性集合均不能满足挑战策略；对手提交两个等长消息和挑战策略，获得其中一个的加密后猜测是哪一个。附录 A 在通用双线性群模型与随机预言机模型中分析对手优势：将挑战项与随机项比较，跟踪可通过群、配对及哈希查询得到的表达式，再界定意外代数碰撞概率；定理给出与 O(q²/p) 相关的优势上界，q 是查询获得群元素总数的界，p 是群的阶。这是证明结构概述，具体条件、常数和推导以原文为准。（来源：第 3.1 节、附录 A，PDF 第 4、12–14 页）


## 17. 安全结论的边界 [BSW 2007, PDF 第6、10、12页]

论文明确使用通用群及随机预言机模型，不是基于某个具体曲线、具体哈希实现的全面安全审计。正文先讨论选择明文安全，并提及可采用额外变换探索选择密文安全；不能将此写成原始构造无条件具备所有 CCA 安全性质。论文的安全证明不涵盖密钥泄露、恶意授权机构、应用漏洞或所有部署风险。（来源：第 4.3、6 节及附录 A，PDF 第 6、10、12 页）


## 18. 撤销、数值属性及工程实现 [BSW 2007, PDF 第3、7–10页]

论文讨论用到期信息辅助撤销，并指出密钥更新和存储等代价；还将整数属性编码成位属性，再用树表达整数比较。这些是特定方案讨论，不等于提供通用实时撤销方案。论文实现的 cpabe 工具包使用 PBC，含 setup、keygen、enc、dec，并在当时条件下评测；结果不能直接代表今天的性能、安全强度或本项目的实现。论文也没有据此实现多授权中心系统。（来源：第 2、4.3、5 节，PDF 第 3、7–10 页）
