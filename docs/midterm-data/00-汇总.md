## 4. 阈值校准

正负样本 top1 分数分布：

| 分布 | min | p50 | p90 | max |
| --- | ---: | ---: | ---: | ---: |
| 正样本（41 案） | 0.633 | 0.772 | — | 0.916 |
| 负样本（10 条不可回答问题） | 0.529 | 0.623 | **0.738** | 0.744 |

正样本第 5 名的分数最低为 0.483（中位 0.664），因此阈值在 0.45 及以下不会减少任何一次检索的返回条数。

阈值模拟（节选）：

| 阈值 | 正样本少返回 | 正样本被误拒 | 负样本被拦截 |
| ---: | ---: | ---: | ---: |
| 0.15 | 0 | 0 | 0 |
| 0.45 | 0 | 0 | 0 |
| 0.55 | 4 | 0 | 3 |
| 0.65 | 18 | 2 | 5 |
| 0.70 | 25 | 8 | 8 |

**结论**：负样本 p90（0.738）≥ 正样本 min（0.633），两组分布重叠、不可分离。阈值 0.45 以下对正样本零损失但拦不住负样本；0.65 以上开始误拒正样本。因此保持 `score-threshold = 0.15`，拒答由系统提示词承担。这是基于数据的决策，不是未校准。
