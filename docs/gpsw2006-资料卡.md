# GPSW 2006 KP-ABE 文献资料卡

- 标题：Attribute-Based Encryption for Fine-Grained Access Control of Encrypted Data。
- 作者：Vipul Goyal、Omkant Pandey、Amit Sahai、Brent Waters。
- 本地资料：用户提供 `2006-309.pdf`，为 IACR ePrint 2006/309 完整版本，28 页；在线条目 https://eprint.iacr.org/2006/309 。
- 对应会议：ACM CCS 2006，89–98，DOI https://doi.org/10.1145/1180405.1180418 。在线 ePrint 说明会议论文是扩展摘要、本 PDF 是完整版；二者版式与页码不可混用。
- 本笔记与 QA 的页码均为本地 PDF 页序 1–28，而非 CCS 出版页码。
- 内容：KP-ABE、访问树与线性秘密共享、选择性集合安全模型、密钥委托、审计日志和广播加密。
- 章节：第 1–2 页摘要/引言；第 5–6 页定义与安全模型；第 7–12 页小属性域构造及证明；第 12–15 页大属性域构造；第 15–17 页密钥委托；第 17–20 页应用及讨论；第 23–28 页附录。
- 范围：选择性集合安全是论文设定下的结论，不能直接推广至所有攻击模型或具体实现；不同构造的能力不可混为一谈。
