## Qdrant 集合（2026-11-13）

| 集合 | 内容 | 片段数 | 用途 |
| --- | --- | --- | --- |
| `abe_knowledge` | 论文知识笔记 | 19 | 默认检索集合 |
| `abe_knowledge_qa` | 分类 QA 及文献说明 | 28 | 独立保存，默认检索不查询它 |

两个集合使用真实 `OpenAiEmbeddingModel`、百炼 `text-embedding-v4`、1024 维；各自写入前确认集合不存在。检查 Qdrant 中的数量、docId、type、section 和 sourceUrl；没有导入评测集或历史测试材料。数量和元数据检查不证明检索排名或回答质量。

默认配置为 `abe_knowledge`，目前服务一次只连接一个集合；若需要单独检索 QA，启动服务时设置环境变量 `QDRANT_COLLECTION=abe_knowledge_qa`。这只切换集合，不会自动同时检索两个集合或去重。评估混合检索前应明确排序及去重方案。默认的 `include-qa: false` 控制入库扫描，并不决定查询哪个已有集合。

当前服务从配置的 corpus-dir 递归读取非隐藏 `.md` 和 `.txt`；默认工作目录为 module-d-integration 时使用 `../module-a-rag/docs`，以 `.qa.md` 结尾的文件默认跳过。更改 corpus-dir 时需重新检查范围。用户本次授权后，QA 通过单独的临时输入目录和独立集合导入；没有更改默认扫描开关。

## 来源信息

切分器以 Markdown 二级及以下标题作为章节，记录相对路径，并从 front matter 获取标题、类型和 sourceUrl。每个正式语料章节标题包含论文标识和 PDF 页序。检索响应返回 type 和 sourceUrl，缺失时返回空字符串；实际引用正确性仍需随检索评估。检查表明两个集合所有点均有 section 和 sourceUrl。

## 测试和费用

字符直方图假 Embedding 已从测试源码删除；Qdrant 和真实 Embedding 测试要求显式设置 `-Dabe.integration.real=true` 且提供 API Key 才运行，以免普通 Maven 测试意外收费。测试上下文显式导入业务配置并断言实际模型类型。旧有含假向量的测试集合未删除，不能用于真实模型效果评估。

正式导入只对知识笔记和 QA 分别执行一次，未运行额外付费查询；精确费用和用量以服务商账单为准。知识库内容更新时，现有 ID 采用内容哈希，不自动删除旧片段；增量更新和清理策略需要先设计再执行，不能直接重建或删除用户数据。
