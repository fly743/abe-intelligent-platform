# Chase 2007 MA-ABE 文献资料卡

- 标题：Multi-authority Attribute Based Encryption。
- 作者：Melissa Chase。
- 出版：Theory of Cryptography Conference（TCC 2007），Lecture Notes in Computer Science 4392，515–534 页，Springer。
- DOI：https://doi.org/10.1007/978-3-540-70936-7_28
- 出版页面：https://link.springer.com/chapter/10.1007/978-3-540-70936-7_28
- 本地 PDF 20 页；本文件引用 PDF 页序，期刊集出版页码 = PDF 页序 + 514。
- 内容：多属性授权机构、可信中央机构、全局用户标识、跨机构抗合谋、阈值方案及大属性域扩展。
- 章节：第 1–4 页背景与设计；第 5–6 页模型与安全游戏；第 7–10 页基础构造发展；第 11–15 页含中央机构构造和证明；第 16–18 页大属性域和复杂访问结构；第 19–20 页扩展及讨论。
- 范围：该方案不是完全去中心化；中央机构持有系统主秘密并须可信。抗合谋和机构损坏结论取决于其安全游戏和限制，不能表述成任意机构联合都不影响安全。
