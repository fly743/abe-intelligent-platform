# B 模块 Java 示例代码生成

## 目标和范围

输入策略和用户属性，生成项目内可编译运行的 Java 示例，展示系统初始化、用户密钥生成、加密和解密。示例调用已有 `BswCryptoService`，不复制密码学核心；从标准输入读取明文字节至 EOF，不把明文或密钥写入源码。生成、编译和运行分别报告，生成成功不代表验证成功。

## 当前实现

`JavaExampleGenerator.generate(policy, attributes)` 调用现有策略解析器和属性校验，将策略安全编码到固定模板，返回 `AbeExample.java` 和项目内运行说明。明文不在生成接口中传入。示例支持空输入、保留换行，明文上限为 1 MiB；属性不满足时返回独立状态。属性按现有 ASCII 命名规则校验，策略使用 Base64 嵌入源码。

`DockerExampleExecutor` 可使用 Docker 原型编译并运行固定模板，已验证代表性的授权与拒绝场景；不接收外部源码。容器异常清理、超时和统一结果等基础流程仍需完善。详细记录见 [受限执行方案](B模块受限执行方案.md)。

## 验证与剩余工作

`./module-b-codegen/scripts/check-java-generator.ps1` 可复现生成代码的编译和普通进程运行验证，覆盖重复属性的授权与拒绝、非法输入、中文、特殊字符、空内容及大小边界。`./module-b-codegen/scripts/check-docker-executor.ps1` 可在有 Docker 权限的环境检查执行器的代表性场景。两者的验证范围见对应脚本和 [开发计划](B模块开发计划.md)，不构成密码学安全审计。

后续需提供统一调用入口，使调用方获得生成源码、依赖说明、编译和运行状态及错误分析，并继续处理 Docker 超时与清理。首版依赖本项目已准备的固定版本 BSW 工件，不提供独立 Maven 分发；完整密钥管理和通用沙箱不作为当前阶段验收条件。

上游采用旧式固定配对参数，jPBC 1.2.1 原始许可仍待核查；公开参数恢复遗漏 `f`，不支持依赖它的委托。结构检查不证明群元素的密码学有效性。

## 统一入口核心场景回归（2026-11-16）

通过 `AbeCodegenService.generateAndVerify` 实际使用 Docker 回归：普通 AND/OR 策略与中文换行、重复属性策略两条授权路径（其中一条为空明文）、属性不足拒绝、非法策略的生成失败和后续阶段未执行，均符合预期。确认生成文件不包含检查用明文。源码调用链将统一入口得到的同一个生成结果传给执行器，执行器从该结果读取源码并传入容器；这项一致性依据代码检查，未对容器内源码单独取证。验证不涵盖所有策略或安全场景。
